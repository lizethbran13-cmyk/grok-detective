# Grok Detective

A bright, cartoony 3D co-op detective game for phones and desktop.

- Explore 5 places: Town Square, Mansion, Museum, Docks and the Forest Cabin
- 5 mysteries (Easy to Hard). The culprit, red herring and clue spots change every game
- Search objects, interview suspects and witnesses, keep everything in your casebook
- Accuse the culprit with the key evidence. Wrong guesses give a hint, never a game over
- Stuck? The magnifying-glass LENS makes hidden clues glow
- Play solo or online co-op with up to 3 detectives (5-letter room code, or start from the Grok Arcade lobby)

Play: https://lizethbran13-cmyk.github.io/grok-detective/
